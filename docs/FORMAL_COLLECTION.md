# 正式实验操作清单

本文只覆盖Neuracle（博睿康）正式数据采集，不包含模型训练、实时解码、Unity或其他设备。

## 一、实验前一天

- 在正式电脑完成 [首次部署](../INSTALL.md)。
- 完成无硬件演练和短硬件预采集。
- 确认电脑全屏、左右手动画、箭头、自动休息和手动暂停均正常。
- 确认博睿康原生软件能够录制原始文件。
- 准备足够磁盘空间和备用移动硬盘。
- 关闭睡眠、屏保、自动更新、通知和不必要的后台程序。

当前Python采集器在session正常结束后统一导出主要文件。为防止程序或电脑中途异常，正式
实验必须同时使用博睿康原生软件录制一份原始数据作为备份。

## 二、被试到场前

1. 接通电脑电源并确认至少20GB可用空间。
2. 连接放大器、电极帽和实验所需线缆。
3. 打开博睿康原生采集软件并连接设备。
4. 确认硬件采样率为250Hz。
5. 在原生软件中检查通道、参考、地和阻抗。
6. 打开JellyFish并开始数据转发。
7. 验证本机端口：

```powershell
Test-NetConnection 127.0.0.1 -Port 8712
```

8. 验证EEG数据：

```powershell
Set-Location D:\path\to\oi-mi
.\.venv\Scripts\python.exe cli.py probe-device --device neuracle --duration 5
```

9. 启动GUI：

```powershell
.\.venv\Scripts\python.exe cli.py gui
```

不要关闭启动GUI的PowerShell窗口。

## 三、被试准备

1. 记录被试编号，避免使用姓名等直接身份信息。
2. 佩戴电极帽并处理阻抗。
3. 让被试双手自然放松，前臂得到支撑。
4. 调整屏幕距离和座椅，保证箭头与动画清楚可见。
5. 告知被试不要实际握拳、抬手或绷紧肩膀。

推荐指导语：

> 每个trial先注视绿色十字2秒，随后观察2秒左手或右手动作提示。箭头出现后的4秒内，
> 按照动画节奏持续想象对应手完成“握拳—松开”，大约两轮，但双手不要实际运动。
> 动画和箭头阶段尽量不要眨眼或移动。如果感到疲劳，可以点击“我要休息”。

## 四、GUI正式启动顺序

1. “设置”：填写正确被试ID，设备选择 `Neuracle`，无硬件模式关闭。
2. “连通检测”：至少检测5秒并确认返回 `59×800`。
3. 阻抗：只在博睿康原生软件中检查；GUI不提供阻抗页面。
4. “数据采集”：可再次运行“画面测试”。
5. 点击“进入正式采集流程”，完整展示指导页。
6. 点击“进入电脑全屏”。
7. 在博睿康原生软件中开始备份录制。
8. 确认被试准备好后点击“开始正式采集”。

正式流程为9个block、每个100个有效trial，共900个。纯trial时间120分钟，8次自动休息
共24分钟，计划总运行时间约144分钟；手动休息会继续延长。

## 五、采集过程中

- 不要刷新浏览器、关闭标签页、关闭PowerShell或启动训练/实时解码。
- 不要改动JellyFish转发设置、采样率或通道。
- 观察博睿康原生波形和JellyFish连接状态。
- 有效trial进度位于刺激首屏下方；工作人员需要查看时向下滚动，查看后向上滚动返回刺激画面。
- 每完成100个有效trial自动休息180秒，结束后自动继续。
- `Esc` 只退出电脑全屏，不会停止采集。
- 左上角 `≪` 会请求暂停并离开刺激页，不应当作普通返回按钮使用。

### 手动暂停

点击“我要休息”后：

1. 当前attempt立即作废；
2. 连续EEG和审计事件仍保留；
3. 该attempt不进入有效窗口；
4. 点击“继续采集”后重新采集同一个计划trial。

## 六、正常结束

最后一个trial结束后不要立刻关闭程序。项目还要执行：

1. 停止JellyFish数据流连接；
2. 写入连续EEG和事件；
3. 对整段连续EEG预处理并从250Hz降到200Hz；
4. 按运动想象开始事件切取4秒窗口；
5. 执行窗口质量控制；
6. 计算文件校验和并更新元数据。

等GUI显示完成路径后，再停止博睿康原生备份录制。

## 七、现场验收

确认session目录包含：

```text
continuous_eeg.npy
events.json
metadata.json
mi_windows.npz
```

检查 `metadata.json`：

- `source_sfreq` 为250；
- `sfreq` 为200；
- `n_channels` 为59；
- `formal_trial_count` 和 `trials_collected` 为900；
- `model_activity` 为 `none`；
- `integrity.status` 为 `complete`；
- `integrity.packet_loss_count` 为0。

窗口可能因质量控制少于900个；如果少于900，应查看质量拒绝统计，而不是手动伪造窗口。

## 八、异常处理

如果JellyFish断开、电脑卡死或程序报错：

1. 记录发生时的block、trial和屏幕状态；
2. 停止本次session，不要把不同session文件手动拼接；
3. 保留项目目录、`.runtime`状态和博睿康原生备份；
4. 修复连接后使用新的session重新采集；
5. 不要删除失败记录，留作审计。

数据结构与对齐细节见 [数据与时间对齐](DATA_FORMAT.md)。
